# Portafolio personal — Duvan Andres Larrahondo Bonilla

Sitio estático construido con HTML, CSS y JavaScript, preparado para publicarse en GitHub Pages.

## Archivos

- `index.html`: estructura, textos y secciones del portafolio.
- `styles.css`: diseño adaptable, tema blanco y negro, composición y animaciones.
- `script.js`: menú móvil, indicador de desplazamiento y animaciones de entrada.

## Antes de publicar

1. Abre `index.html`.
2. Busca `TU_CORREO@ejemplo.com` y reemplázalo por tu correo profesional.
3. Reemplaza los enlaces genéricos de GitHub y LinkedIn por los enlaces de tus perfiles.
4. Revisa todos los textos y confirma que el estado de cada proyecto sea correcto.
5. Recuerda que GitHub Pages publica el sitio en internet. No añadas contraseñas, documentos privados, teléfonos personales ni información que no quieras hacer pública.

## Probar localmente

Abre la carpeta en Visual Studio Code y abre `index.html` en un navegador. Para una experiencia cómoda puedes instalar la extensión **Live Server**, hacer clic derecho sobre `index.html` y seleccionar **Open with Live Server**.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub. Puedes llamarlo `duvan-portfolio`.
2. Sube los archivos de esta carpeta a la raíz del repositorio.
3. Abre `Settings` → `Pages`.
4. En `Build and deployment`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa `Save`.
6. Espera a que termine la publicación. La URL aparecerá en la misma sección de Pages.

La URL suele tener el formato `https://TU-USUARIO.github.io/duvan-portfolio/`. Sustituye `TU-USUARIO` por tu nombre de usuario real de GitHub.
